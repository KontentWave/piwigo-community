# Plugin Integration Map

Last updated: 2026-07-31

## Piwigo core

| Community surface    | Piwigo surface                                                                                | Contract and coupling                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Risk                                                                                                                                                                                                                                                                                               |
| -------------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.inc.php` hooks | `init`, gallery/admin location hooks, `ws_add_methods`, `sendResponse`, deletion/cache events | Handler order and mutable globals control authorization and post-upload moderation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Critical: admin status is changed before core webservice authorization.                                                                                                                                                                                                                            |
| Upload webservices   | `pwg.images.add*`, `upload*`, `check*`, `uploadCompleted`                                     | Community replaces the upload methods and `pwg.images.uploadCompleted` for enabled non-admin users with method-specific wrappers. Both completion public names share one scoped service that validates token, category grant/existence, ownership, guest/generic session provenance, and exact association-or-lounge eligibility; it uses sorted stable per-image locks and a canonical receipt, never core `empty_lounge()`. Genuine administrators and `faked_by_community=false` retain core callbacks.                                                                                                                              | Ambient elevation remains for `pwg.images.exist`, `pwg.images.checkUpload`, `pwg.images.checkFiles`, `pwg.session.getStatus`, and tag creation. File receipts provide retry/overlap deduplication but not crash-safe notification delivery or transactional completion.                            |
| Legacy chunk upload  | `pwg.images.addChunk`, `pwg.images.add`, `add_uploaded_file()`                                | Community now replaces both `pwg.images.add` and `pwg.images.addChunk` with same-name wrappers that reject non-hex 32-char `original_sum` values before delegating; for `uniqueness_mode=filename` it also performs an escaped filename precheck and disables the downstream core filename uniqueness branch for that request.                                                                                                                                                                                                                                                                                                          | Core still uses `original_sum` for chunk paths, regex cleanup, and uniqueness SQL, so this safety depends on Community method registration remaining the final upload-method override before core handling.                                                                                        |
| Image edit/delete    | `pwg.images.setInfo`, `pwg.images.delete`, core mutation callbacks and `delete_elements()`    | Community replaces both methods for enabled non-admin users with exact-schema, POST-only wrappers. A shared policy strictly canonicalizes the complete target set and requires an effective upload grant, ownership, guest/generic session provenance, and exclusively authorized current category associations immediately before one core delegate call. `setInfo` validates local metadata/category/tag/mode inputs, removes caller-supplied `level`, and rejects request-global `tag_list`; `delete` validates its token before authorization queries. Genuine administrators and `faked_by_community=false` retain core callbacks. | Safe delegation depends on Piwigo 16.x callbacks continuing to perform the canonical relation, tag, activity, hook, cache, and deletion side effects without an internal administrator-status requirement. Category/tag creation and remaining elevated helper methods are separate open surfaces. |
| Album creation       | `pwg.categories.add`, `create_virtual_category()`                                             | Parent must be in effective create grants; user albums are provisioned lazily.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Creation and ownership assignment are separate writes.                                                                                                                                                                                                                                             |
| Tags                 | `pwg.tags.add`, admin tag listing                                                             | Any Community-enabled user is elevated for tag creation; admin list is replaced with a Community wrapper.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Gallery-global tag namespace can be modified by limited uploaders.                                                                                                                                                                                                                                 |
| Upload storage       | `add_uploaded_file()`, upload buffer, PclZip                                                  | Plugin uses core persistence and archive library.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Quota/moderation occur after writes; archive limits are plugin-owned and absent.                                                                                                                                                                                                                   |
| Tables               | images, image-category, categories, users/groups, activity, config                            | Plugin adds `categories.community_user` and two plugin tables.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Core-table column ownership complicates uninstall/migrations; MyISAM blocks transactions.                                                                                                                                                                                                          |
| Tokens/errors        | `get_pwg_token()`, `check_pwg_token()`, `PwgError`                                            | Both Community upload-completion entry points and `pwg.images.delete` are POST-only and validate `pwg_token` before side-effect queries; several admin pages still do not.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Error handling is inconsistent across page, hook, and webservice boundaries.                                                                                                                                                                                                                       |
| Cache                | user/category cache and plugin config cache key                                               | Random global key invalidates session permission caches.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Broad invalidation and eventual session refresh behavior.                                                                                                                                                                                                                                          |

## High-risk coupling rules

- Never grant core admin status to represent a Community capability.
- Authorization must happen before core upload/category/tag writes, for every destination and object, including replacement, format attachment, and update modes.
- Validate `original_sum` as exactly 32 hexadecimal characters before filesystem or database use; escaping remains mandatory at each sink, including the Community post-upload checksum lookup and filename uniqueness precheck.
- Plugin table and image/category/filesystem transitions need one recoverable workflow.
- Changes to Piwigo webservice registration, handler priority, upload response shape, token rules, user status semantics, or category schema require Community regression tests.
- Upload completion must never delegate Community requests to global `empty_lounge()`; preserve exact `(image_id, category_id)` scoping, canonical hook payloads, stable lock inodes, and compatibility for both public method names.
- Changes to Two Factor helper names, bootstrap constants, profile URL semantics, or webservice policy require an explicit compatibility review.
